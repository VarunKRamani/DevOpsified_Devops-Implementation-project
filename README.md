# DevOpsified_Devops-Implementation-project

**Implementing End to End DevOps on a Golang web application**

We will implement the following things 

- Containerization of the application (Multi Stage Docker Build)
- Creating Kubernetes Manifests
- CI using GitHub Actions
- CD using Argo CD
- Kubernetes Cluster creation and Setup
- Helm chart creation and Configuration
- Ingress controller creation and configuration to expose application
- DNS mapping
- End to End CI/CD demonstration
